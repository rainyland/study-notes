**数据结构 · 第 08 章「图」的一页式复习笔记。** 从顶点和边讲起，一路到存储、遍历、连通性、最小生成树、最短路径，最后用一张表复盘高频考点。

| # | 小节 | 讲清楚的一件事 |
|:--:|---|---|
| 01 | 认识图 | 顶点是对象，边是对象之间的关系；有无箭头区分有向与无向 |
| 02 | 图的存储 | 邻接矩阵看"有没有边"，邻接表看"邻居是谁" |
| 03 | 图的遍历 | DFS 沿一条路走到底，BFS 一层一层往外推 |
| 04 | 连通性 | 能不能从一个顶点走到另一个顶点 |
| 05 | 生成树与最小生成树 | 用最少的边把所有顶点连起来：Prim 与 Kruskal |
| 06 | 最短路径 | Dijkstra 单源最短路，Floyd 全源最短路 |
| 07 | 高频考点 | 一页表格复盘，专治"看着会、做题错" |
| 08 | 自检三问 | 用三个问题确认自己真的懂了 |
