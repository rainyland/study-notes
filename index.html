数据结构 · 第八章学习笔记

图：把“点和点之间的关系”真正学明白

从零理解图的概念、存储、遍历、连通性、生成树与最短路径

树描述的是层级关系，图描述的是更自由的连接关系。城市道路、社交关系、网络设备、课程依赖……很多现实问题，都可以抽象成一张“图”。

01 先认识图：点和边组成的关系网

图（Graph）由两个集合组成：顶点集合 V 和边集合 E，通常记作 G=(V,E)。

  • 顶点（Vertex）：表示对象，例如城市、用户、设备。
  • 边（Edge）：表示对象之间的关系，例如道路、好友关系、网络连接。
图1：顶点是对象，边是对象之间的连接。图中没有箭头，因此是无向图。

有向图和无向图

图2：有没有箭头，是区分有向图和无向图最直接的方法。
记忆：无向边没有方向；有向边有起点和终点。看到箭头，先判断方向，再数入度、出度。

02 图怎么存进计算机：邻接矩阵与邻接表

图在纸上可以画出来，但计算机需要用数据结构保存顶点之间的连接。最常见的两种方式是邻接矩阵和邻接表。

邻接矩阵：用表格记录“有没有边”

假设有 A、B、C、D 四个顶点。若两个顶点之间有边，就在对应位置记 1；没有边就记 0（这是无权图的常见表示方式）。

图3：矩阵是 n 行 n 列。4 个顶点对应 4×4；有边的位置记为 1。
  • 矩阵大小只由顶点数 n决定：n×n。
  • 查询两个顶点之间是否有边很快。
  • 即使边很少，也要开出 n×n 的空间。
  • 适合边比较多的稠密图。

邻接表：每个顶点记下自己的邻居

图4：邻接表不铺满整个矩阵，只保存实际存在的邻接关系（示意）。
  • 只记录真实存在的边，通常更节省空间。
  • 适合边比较少的稀疏图。
  • 要查两个指定顶点是否相邻，可能需要在邻居链表中查找。
比较邻接矩阵邻接表
存储形式二维表格每个顶点的邻居列表
空间特点约与 n² 相关约与 n+e 相关
更适合稠密图稀疏图
记忆关键词查边方便节省空间
易错点：邻接矩阵是 n×n，取决于顶点数，不取决于边数。100 个顶点，无论只有 5 条边还是 500 条边，矩阵都是 100×100。

03 图的遍历：DFS 与 BFS 是两种走法

遍历，就是从某个顶点出发，把能够访问到的顶点按规则访问一遍。最重要的两种方法是深度优先搜索 DFS 和广度优先搜索 BFS。

图5：后面用这张图比较 DFS 和 BFS。假设邻接点按字母顺序访问。

DFS：深度优先，先沿一条路走到底

从 A 出发，先走 B；从 B 继续走 D。D 没有没访问过的邻居，就回退到 B，再走 E。最后回到 A，走 C。

图6：DFS 顺序 A → B → D → E → C。走不下去时，回到上一个分岔点。

理解关键词：深入、走到底、回退。实现时常借助栈（或递归调用栈）。

BFS：广度优先，先把同一层走完

从 A 出发，先访问 A 的所有邻居 B、C；再依次访问下一层的 D、E。

图7：BFS 顺序 A → B → C → D → E。先访问离起点近的，再访问更远的。

理解关键词：分层、同层优先。实现时使用队列。

对比DFSBFS
中文深度优先广度优先
访问方式一条路深入后回退一层一层向外扩展
常用辅助结构栈队列
无权图最短路径不保证可以求最少边数路径
必背对应：DFS → 栈；BFS → 队列。无权图求最短路径（按边数）→ BFS。

04 连通性：能不能从一个点走到另一个点

在无向图中，如果任意两个顶点之间都存在路径，这个图就是连通图。如果一个图没有整体连通，它可能由几个互不相连的部分组成，每个最大的连通部分叫一个连通分量。

图8：左边 A、B、C 是一个连通分量；右边 D、E、F 是另一个，共 2 个。

判断连通分量时，可以想象从一个点出发，把所有能到达的点圈成一组。再找还没被圈进去的点，继续圈。最后有几组，就是几个连通分量。

有向图要更谨慎：有向图常区分强连通与弱连通。强连通要求顶点之间按箭头方向能够相互到达；弱连通则暂时忽略边的方向后判断是否连通。

05 生成树与最小生成树：用最少的边把点连起来

对于一个连通的无向图，生成树要包含图中所有顶点，并且不能有环。若图有 n 个顶点，生成树一定恰好有 n−1 条边。

图9：5 个顶点的树有 4 条边；所有顶点连通，且没有环。

如果图中的边带有权值（例如修路成本、布线费用），希望把所有顶点连起来，同时总权值最小，这就是最小生成树（MST）。

两种常考算法

  • Prim（普里姆）：从一个顶点开始，每次选择一条连接“已选顶点集合”和“未选顶点”的最小权值边，把新顶点纳入。常作为稠密图的优先选择。
  • Kruskal（克鲁斯卡尔）：把边按权值从小到大排序，依次选择不会形成回路的边，直到连通。常作为稀疏图的优先选择。
MST 三个关键词：包含所有顶点、没有回路、总权值最小。若所有边权值互不相同，最小生成树唯一；若存在相同权值，可能不唯一。

06 最短路径：从一个地方到另一个地方怎么走最省

最短路径讨论的是两个顶点之间，路径长度最小的路线。这里要先看题目有没有权值。

图10：无权图中比较路径长短，通常看经过的边数。
  • 无权图：每条边可视为同样长度，BFS 可以找到从起点到各点的最少边数路径。
  • 带权图：边的权值代表距离、时间或费用等，不能只数边数，需要使用适合带权图的最短路径算法，例如 Dijkstra（满足非负权值条件）。
特别注意：最小生成树和最短路径不是一回事。最小生成树追求“把所有顶点连起来的总成本最小”；最短路径追求“指定起点到指定终点的路线最短”。

08 最后，用三个问题检查自己是否真的懂了

  1. 一个图有 100 个顶点、只有 5 条边，通常更适合用邻接矩阵还是邻接表存储？
    提示：考虑空间是否浪费。
  2. 从 A 出发，想在无权图中找到到其他顶点的最少边数路径，应该用 DFS 还是 BFS？
    提示：谁是一层一层向外扩展的？
  3. 一个无向连通图有 8 个顶点，它的生成树有多少条边？
    提示：生成树边数公式 n−1。
本章真正要建立的理解：
图不是一堆孤立的定义，而是一套描述关系的方法。先看顶点和边，再看如何存储；想知道如何访问，就学 DFS 和 BFS；想判断是否连通，就看连通分量；想用最低成本连接所有点，就看最小生成树；想找两点之间的最短路线，就看最短路径算法。
学习建议：先对着图讲出自己的理解，再记忆术语和公式。做题时先判断题目属于哪一个知识模块，不要急着套答案。
